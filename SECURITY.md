# Security Policy

## Scope

This repository contains public documentation and a small static validator. It does not run a hosted service and should never contain secrets or personal data.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected security problem, exposed secret, or privacy concern. Instead, use GitHub's private security reporting feature for this repository when it is available, or contact the repository owner through a private channel.

Include a clear description, affected file or workflow, steps to reproduce where applicable, and any suggested mitigation. Please avoid including credentials or other sensitive data in the report.

## Response

Reports will be reviewed as time permits. Valid concerns will be addressed by removing exposed information, updating the affected documentation or validation, and documenting the fix in the repository history when safe to do so.
