# Generic GitHub Profile README Checklist

This checklist is deliberately generic. Replace bracketed placeholders only in the active profile repository, after confirming that every detail is appropriate for public display.

## Before publishing

- [ ] Confirm the profile repository is named exactly after the GitHub account.
- [ ] Keep the README focused on public, professional, and durable information.
- [ ] Remove personal contact details, credentials, private links, and sensitive metadata.
- [ ] Check every external link and image URL.
- [ ] Preview the rendered Markdown on GitHub.
- [ ] Review the profile while signed out or in a private browser window.

## Optional sections

Choose only sections that add useful public context:

- Brief introduction
- Current focus or selected public work
- Skills or technologies
- Open-source contributions
- Public contact channel
- Pronouns or accessibility preferences
- Lightweight activity widgets, only when their data source and privacy impact are understood

## Minimal template

```md
# [Display name or handle]

[One or two public sentences describing current interests or work.]

## Focus

- [Public topic, project, or learning goal]
- [Public topic, project, or learning goal]

## Selected public work

- [Repository or project link] — [short, factual description]

## Contact

- [Optional public contact method]
```

## Maintenance cadence

Review the profile README after a role, focus, or public-project change, and at least twice each year. Remove stale claims rather than keeping a long historical record.
